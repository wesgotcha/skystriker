# SKY STRIKER · 2.5D 飞机弹幕大战

用 **C++17 + raylib 6 + raylib-cpp** 从零实现的横版弹幕射击游戏。
机体是真正的 3D 模型（glTF），其余全部是 2D 像素素材——两者在同一个渲染帧里合成，形成"2.5D"观感。

---

## 1. 特性

| 类别 | 说明 |
|---|---|
| 渲染 | 1920×1080 逻辑分辨率 → 等比缩放到任意窗口，窗口可自由拉伸、支持高分屏（Per-Monitor V2 DPI） |
| 2.5D | 正交俯视相机（倾角 26°），1 世界单位 = 1 逻辑像素，3D 机体与 2D 弹幕坐标完全对齐 |
| 中文 | 运行时解析 TTF `cmap` 自动加载字库，Source Han Sans SC 全部字形可用 |
| 界面 | 12 屏完整流程：启动 / 主菜单 / 机库 / 简报 / 战斗 / 暂停 / 阵亡 / 结算 / 设置 / 排行 / 确认 / 转场 |
| 玩法 | 5 波编队（打完当波全部敌人才进下一波）+ 终局 Boss、3 类敌机 + 1 Boss、血条显示、Shift 闪身、火力升级、爆弹清屏、连击计分、三星评价 |
| 音频 | 素材包没有音频，全部音效由代码合成波形（射击/命中/爆炸/爆弹/拾取/UI） |
| 存档 | `save.dat`：最高分、星级、机体与配色、音量与按键设置 |
| 双人 | 同屏组队 / 同屏对战 / 联机组队 / 联机对战；联机走 TCP 47800 传输入 + UDP 47801 广播发现，锁步同步 |

## 2. 编译与运行

### 依赖

- MinGW-w64 g++（本工程用 15.2.0 验证）
- `raylib 6.2`（已放在 `vendor/raylib-6.2_win64_mingw-w64/`）
- `raylib-cpp 6.0.3`（header-only，已放在 `raylib-cpp-6.0.3/`）

### 一键编译

```bat
build.bat
```

会先跑 `tools/gen_charset.py` 校验所有上屏中文是否被字体覆盖，然后编译出 `build\SkyStriker.exe`。

### 运行

```bat
run.bat
```

或在工程根目录直接 `build\SkyStriker.exe`（程序会自动向上寻找 `assets/`，也可以把 exe 放到 `build\` 下双击运行）。

## 3.1 战斗设计

### 五波编队

| 波次 | 编队 |
|---|---|
| 1 | 5 × C |
| 2 | 2 × C + 1 × B |
| 3 | 3 × C + 1 × A |
| 4 | 5 × C + 1 × B + 1 × A |
| 5 | BOSS + 3 × C + 2 × A |

**当波敌人不清空就不会进下一波**：敌机不会自行飞出画面消失（A 冲撞冲出边界后会从右侧重新进场），
所以"漏怪"不会卡住关卡。敌机巡航锚点全部落在画面右半边（x ∈ [1250, 1720]），
玩家活动区被限制在左侧（x ≤ 1150），横版对射的空间关系始终成立。

### 四类敌机

| 类型 | 外观 | 血量 | 行为 |
|---|---|---|---|
| **C** 侦察机 | Spitfire | 30 | 单发瞄准弹（9 伤害），1.6–2.3s 一发 |
| **B** 炮击机 | Imperial | 130 | 常态三向散射（各 9 伤害）；每 5.4–7s 蓄力 0.55s 后打一发**大炮弹（25 伤害 = 1/4）** |
| **A** 冲锋机 | Insurgent | 72 | 巡航 2.2–3.4s 后**蓄力 1.05s 锁定方向**，然后 1500px/s 直线冲撞：撞到玩家自身爆炸并造成 **34 伤害 = 1/3**，冲空则从右侧重新进场 |
| **BOSS** | Zenith | 1200 | 三向 / 五向 / 双发大炮弹 / 冲撞 **随机发动**，血量越低出手越快（1.5s → 0.85s） |

A 的蓄力是整套战斗的核心读牌点，预警给足四层：

1. 一条贯穿全屏的**红色危险走廊 + 流动虚线**（锁定方向在蓄力瞬间固定，玩家只要离开这条线就能躲）
2. 机体外圈的**收缩蓄力环**
3. 机体上方的**红色警示三角 + "锁定"字样**
4. 屏幕四周**泛红脉冲**，底部弹出 `SHIFT + 方向  闪避` 操作提示

### 伤害与血量

玩家 100 点装甲，受伤后 0.85s 无敌，且火力等级 −1。

| 来源 | 伤害 |
|---|---|
| 普通弹（C / B 三向 / Boss 三向五向） | 9 |
| 大炮弹（B / Boss） | 25（1/4） |
| 冲撞（A / Boss） | 34（1/3） |
| 修复道具 | +35 |

### 闪身

`Shift + 方向` 触发：0.2s 内沿该方向位移 410px，期间获得 0.34s 无敌，冷却 0.8s。
冲刺过程会留下 3D 残影 + 2D 速度线。右下 HUD 有冷却条，就绪时闪"就绪"。

## 3.2 双人模式与联机

主菜单新增「双 人」，四种玩法：

| 模式 | 说明 |
|---|---|
| 同屏合作 | 两人共用一台机器打五波关卡，Boss 也在；敌机锁定最近的玩家，道具谁捡谁用 |
| 同屏对战 | 两人各守左右半场互相射击，先清空对方装甲的获胜（一发 6 点伤害） |
| 联机合作 | 局域网两台机器一起打关卡；两端各控制一名玩家（主机 1P / 客户端 2P） |
| 联机对战 | 两人各守左右半场互相射击，先清空对方装甲的获胜（一发 6 点伤害） |

### 同屏按键

| 操作 | 1P | 2P |
|---|---|---|
| 移动 | WASD | ↑↓←→ |
| 射击 | J / 空格 | 小键盘 1、`.` |
| 爆弹 | K / L | 小键盘 2、`,` |
| 闪身 | L（Shift+方向同样有效） | 小键盘 3、`/` |
| 换人（机库） | TAB | TAB |

### 联机流程

1. 两台机器在同一局域网，都从主菜单进「双 人」
2. 一台选「建立主机」，界面上会显示本机 IP（优先显示 192.168 / 10 / 172.16–31 这类内网地址）
3. 另一台选「连接主机」，列表里会出现主机（`R` 重新搜索）；列表空时按 `TAB` 可手输 IP
4. 主机看到「2P 已接入」后按 `ENTER` 开始，两端同时进入战斗

端口：**TCP 47800**（战斗数据）、**UDP 47801**（主机广播发现）。第一次运行如果
Windows 防火墙弹窗，需要允许（至少允许「专用网络」）。

### 同步原理（锁步）

两端跑的是**同一份确定性模拟**：种子、机型、配色都写在同一份开局包里，
每 1/60 秒推进一帧，各自只把 7 个按键位（上下左右 / 射击 / 爆弹 / 闪身）发给对方。

- 输入带 4 帧延迟：本机第 N 帧的按键，会在第 N+4 帧生效，用来吸收网络抖动
- 按键的「按下沿」由 World 自己用上一帧状态对比得出，所以跨机器不会漏按/连按
- 每秒互相发一次状态校验和，一旦对不上立刻弹「状态不同步」并断开，不会越玩越飘
- 暂停会同步给对方；任一端的 ESC 都能同时暂停两端，再按一次同时继续
- 对端掉线（进程关掉 / 断网）超过 6 秒，本机弹提示并回到主菜单

## 5. 关键技术点

### 5.1 逻辑画布与高分屏

窗口大小变化时重新计算

```
scale = min(winW/1920, winH/1080)      // 夹在 [0.35, 2.0]
canvas = RenderTexture(1920*scale, 1080*scale)
```

所有绘制先落到 `canvas`，再用 `DrawTexturePro` 贴到窗口中央（多余部分留黑边）。
好处是：**界面布局永远按 1920×1080 写**，而实际渲染分辨率跟随窗口，高分屏下文字依然是原生像素而不是放大糊掉。
鼠标坐标用 `(mx - originX) / scale` 反算回逻辑坐标。

Windows 上在 `InitWindow` 之前调用 `SetProcessDpiAwarenessContext(PER_MONITOR_AWARE_V2)`，
否则 150% 缩放时整个窗口会被系统位图拉伸。

### 5.2 2.5D 相机与战机姿态

机体是 3D 模型，但玩法是纯 2D 的：子弹、判定、HUD 全在屏幕坐标系里。
为了让两者对齐，用**正交相机 + 固定倾角**（`kCamTilt`，从斜上方 28° 俯视 → 偏离竖直 62°）：

```cpp
cam.projection = CAMERA_ORTHOGRAPHIC;
cam.fovy = 1080;                       // 正交高度 = 逻辑高度 → 1 单位 = 1 像素
cam.position = {960, cos(tilt)*d, 540 + sin(tilt)*d};
```

正交投影是仿射变换，所有机体都在同一高度平面上，于是

```
屏幕 x = 世界 X
屏幕 y = (世界 Z - 540) * cos(62°) + 540
```

反解即可把任意屏幕坐标变成机体位置。3D 机体因此能和 2D 弹幕严丝合缝地叠在一起。
机体下方再画一个 2D 椭圆当投影，就有了"飞在海面上"的立体感。

#### 姿态（`src/game/Pose.hpp`）

**姿态是运动的结果，不是输入。** 按键只改变速度，倾角由垂直速度反推，
所以有滞后、有回正、有甩尾；直接把按键映射成倾角会像坦克而不是飞机。

| 轴 | 作用 | 来源 |
|---|---|---|
| 绕 X | 滚转（侧倾） | 唯一由垂直速度驱动的轴 |
| 绕 Z | 俯仰（机头抬/压） | 不独立控制，= 滚转 × 0.35 联动 |
| 绕 Y | 偏航 | 恒为 0（只有 ±90° 的固定朝向把机头摆到 ±X） |

```
目标倾角 = 基准 − 垂直速度 × 系数        // 再钳制
当前倾角 += (目标 − 当前) × (1 − e^(-rate·dt))
```

| | 基准 | 速度系数 | 钳制区间 | 速率 |
|---|---|---|---|---|
| 玩家 | −0.16 | 0.39（规范 0.075 × 5.2） | [−0.55, +0.30] | 9.0 |
| 敌机 | −0.08 | 0.40（规范 0.08 × 5.0） | [−0.40, +0.40] | 7.0 |

上下不对称是刻意的：拉升（−0.55）比俯冲（+0.30）更夸张，俯冲时收敛。
敌机出生时给固定初值（战斗机 −0.08、轰炸机 −0.05），避免第一帧从 0 弹到目标值。

机库复用同一套 `pose::Pose`——只需要挑一个展示角度 `pose::FromRoll(-0.14f)`，
不用再单独写死一套旋转逻辑。

### 5.3 一帧内的 2D / 3D 切换

```
BeginTextureMode(canvas)
  BeginMode2D(zoom)   背景视差层 + 地面阴影
  EndMode2D()
  BeginMode3D(ortho)  所有机体
  EndMode3D()
  BeginMode2D(zoom)   弹幕 / 粒子 / HUD / 界面
  EndMode2D()
EndTextureMode()
```

注意：`EndMode3D()` 之后必须 `rlDisableBackfaceCulling()`，
否则后续 2D 的 `DrawTriangleFan`（切角面板填充）会因为缠绕顺序被判为背面而整片消失。

### 5.4 中文显示

`assets/fonts/*.ttf` 是 Source Han Sans SC 的**子集**（571 字形）。
程序启动时自己解析 TTF 的 `cmap` 表拿到全部码位，再交给 `LoadFontEx`，
所以字库里有什么字就能显示什么字，不需要手工维护码表。

字体按 5 个尺寸预烘焙（正文 22/34/52，标题 40/76），
`DrawTextEx` 按需缩放，小字号取最接近的大图集，避免糊边。

`tools/gen_charset.py` 会扫描源码里所有字符串字面量，报告字体缺失的汉字——
本项目所有上屏文字都通过了这项检查（151 个汉字全覆盖）。

### 5.5 模型换色

每个机体加载 5 张配色贴图（512²，Boss 1024²），绘制时直接替换材质的漫反射贴图，
不改模型本身。glTF 内嵌的 2048² 贴图在加载后立刻释放，避免 11 架机体吃掉几百 MB 显存。

机体使用自写的**无光照着色器**（双面法线 + 双方向光），
既保证暗部细节，又不会被 raylib 默认光照压得过暗。

### 5.6 像素化转场

24×14 网格，每格一个随机延迟，0.31s 变黑 → 切屏 → 0.31s 揭开。

## 6. 调试参数

```bat
SkyStriker.exe --screen=game --demo --god --shot=out.png --warp=95
```

| 参数 | 说明 |
|---|---|
| `--screen=boot|title|hangar|game` | 直接进入某屏 |
| `--overlay=pause|settings|records|briefing|gameover|confirm` | 叠加覆盖层 |
| `--demo` | 自动演示（自动躲弹 + 自动射击） |
| `--god` | 玩家无敌，方便看后期波次与 Boss |
| `--result` | 机库以结算模式打开 |
| `--warp=秒` | 先空跑若干秒再截图 |
| `--shot=路径` | 把逻辑画布导出为 PNG 后退出 |
| `--seq=目录 --seqn=N` | 逐帧抓真实呈现画面（N 帧后退出），用来验证 UI 是否稳定 |
| `--size=1920x1080` | 指定窗口尺寸 |
| `--test-esc=1.0` | 在第 N 秒注入一次 ESC，用来回归覆盖层的关闭流程 |
| `--test-key=R@6` | 在第 6 秒注入一次 R 键（回归「阵亡后重试」等流程） |
| `--force-fail=3` | 在第 3 秒强制阵亡，配合上面两个开关做回归 |
| `--screen=lobby` | 直接进入双人入口 |
| `--mp=coop`、`--mp=versus` | 指定对局模式（配合 `--host` / `--join=IP` 走联机，`--autostart` 连上就开打） |
| `--host`、`--join=127.0.0.1`、`--autostart` | 联机调试入口，等价于在双人界面里手动按键；`tools/net_test.py` 就是靠它跑的 |
| `--fps` / `--state-log` | 帧率日志 / 每秒打印战斗状态（含两名玩家的坐标与血量） |

环境变量 `SKY_NET_LOG=1` 会打印联机握手、每 30 帧的输入位、卡帧时的 tick 快照，
排查"锁步卡住 / 两端不同步"时用。
